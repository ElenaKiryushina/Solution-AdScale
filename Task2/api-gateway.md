**API Gateway для DSP-интеграции**

1. **Маршрутизация и преобразование протокола** - API Gateway получает запрос от DSP-площадки по протоколу **OpenRTB (HTTP/REST), преобразует его** и направляет его по протоколу gRPC в Ad Service (рекламный сервис).
2. **Rate limiting.** API Gateway ограничивает количество запросов от одного клиента. В AdScale три уровня rate limiting:
    a. 50 запросов в минуту из WEB UI работодателя.
    b. 20000 RPS от DNS – площадки.
    c. 50 запросов в минуту для неаутентифицированных запросов по IP — защищает от DDoS-атак.
3. **Аутентификация** API Gateway проверяет **JWT-токен** каждого входящего запроса. Если токен невалиден, Gateway возвращает ошибку (401 Unauthorized), не допуская запросы до внутренних сервисов. Это разгружает сервисы и обеспечивает единую политику аутентификации.
4. **Логирование** - API Gateway логирует каждый запрос - URL, HTTP-метод, статус-код, latency, `user_id` (из JWT), client IP, `user-agent`.
5. **Circuit Breaker** — API Gateway отслеживает количество ошибок при обращении к микросервису и если порог ошибок превышен, «предохранитель» прекращает отправлять запросы к проблемному узлу, возвращая ошибку клиенту, тем самым предотвращая каскадный отказ всей системы.
