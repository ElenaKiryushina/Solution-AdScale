# Проектирование RTB и интеграции с DSP

После достижения  MVP1 спустя 3 месяца после интеграции с новой крупной DSP-площадкой компании AdScale необходимо двигаться к целевому состоянию на горизонте следующих 9 месяцев - когда система поддерживает 50 000 RPS, обеспечивает мультиплатформенную интеграцию, микросервисную архитектуру, событийно-ориентированную обработку, горизонтальное масштабирование и мультирегиональное развёртывание. SLA — 99.9%. Первый шаг - выделение в отдельный микросервис самого критичного RTB-модуля.

Cпроектирована архитектура критичного компонента — RTB-сервиса для интеграции с новой DSP-площадкой с соблюдением требований по времени отклика и надёжности.
