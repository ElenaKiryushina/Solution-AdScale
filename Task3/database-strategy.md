**Database per Service**

| **Сервис** | **Тип базы данных** | **Обоснование** |
| --- | --- | --- |
| Сервис ставок | Cache Redis\nRTB DB - PostgreSQL | Redis для мгновенного чтения кампаний, правил и бюджетов (минимизация Latency)\nСобственная БД (RTB DB) – таблицы AuctionResult, AuctionLogs. Выдача данных остальным сервисам через сообщения в Kafka. |
| Сервис кампаний | PostgreSQL (MDM)\nRead‑Replica | Мастер-БД – рекламодатели, кампании, бюджеты, данные для таргетирования, пороговые значения ставок. Данные нужны для ВСЕХ сервисов - выдача через сообщения в Kafka\nRead‑Replica – для масштабирования чтения и отказоустойчивости (подстраховка Redis) |
| Сервис статистики | Event-oriented DB (ClickHouse) | Большая нагрузка на запись (write‑heavy). Большой поток событий показов и кликов |
| Сервис аналитики | Analytical DB (OLAP) | В БД агрегаты для построения отчетности. История. Поддерживаются тяжелые аналитические запросы. |
| Сервис финансов | Financial DB - PostgreSQL | Обеспечение строгой консистентности (ACID) при списании средств. Использование идемпотентности для обработки повторных запросов. |
