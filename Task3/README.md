# Данные, масштабирование и отказоустойчивость

Чтобы достигнуть SLA — 99.9% при 50 000 RPS, необходимо обеспечить масштабируемость и отказоустойчивось хранилищ каждого миксросервиса.

Отпределен и обоснован тип БД для каждого микросервисиса, описаны стратегии масштабирования и кеширования, архитектура потоковой обработки событий и отказоустойчивость. 

Все документы представлены в формате Markdown, а схемы — в формате PlantUML.
